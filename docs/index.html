使用指南

快速上手 2026.09.20

从选择目标到生成路线，只需要完成下面几步。所有标记仅保存在当前浏览器中。

  1. 01
    选择目标

    左键点击载具可选择或取消目标。也可以右键载具，再选择“设为目标”。

  2. 02
    补充账号状态

    右键载具可标记“已拥有”或设为“途经点”。再次选择相同状态即可取消。

  3. 03
    调整补位偏好

    勾选“自动补位时避开折叠载具”后，算法不会主动用折叠载具补足等级数量。

  4. 04
    开始精确规划

    点击页首或科技树右侧的“精确规划”。下滑查看科技树时，右侧按钮会一直跟随可见区域。

  5. 05
    阅读规划结果

    “必经路线”是前置载具，“等级补足”是为满足下一级解锁数量而自动加入的载具。
