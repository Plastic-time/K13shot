# v1.0.8 配件数据修正

## 本次更新

- Ka-29：移除多出的 S-24 配件，按游戏截图及确认值修正分层研发费用，调整对应挂架前置。共 17 项配件，总计 297,800 RP / 436,000 SL。
- Do 217 J-2：移除游戏截图中不存在的 5 项炸弹解锁，并收起空列。共 14 项配件，总计 5,940 RP / 4,480 SL。
- 英国和日本的 CA-27 Mk.32：第三层挂架由 FRC mk.2 更正为 GLBC mk.3，使用炸弹挂架图标；按用户游戏内确认，该项为 9,000 RP / 9,000 SL。每辆全部配件总计 145,800 RP / 221,000 SL。
- CA-27 旧挂架保存的目标和已研发状态自动对应到新挂架，无需重新标记。
- 网页与下载版使用同一份修正数据，并增加针对费用、前置、总计和保存状态的回归检查。

## 范围说明

本次只修正上述载具的配件数据，不更改已确认的界面、载具研发费用、科技树规则或规划算法。配件等级数量门槛保持原样。

整体数据基准仍为 2.59.0.17；Ka-29、Do 217 J-2 结合 2.59.0.22 配置和游戏截图作局部修正，CA-27 挂架名称与费用采用用户提供的游戏截图和确认值。这不代表全量快照已升级至 2.59.0.22。Ka-29 和 Do 217 J-2 的银狮总量仍依据游戏配置，未由截图逐项确认。

## 下载与运行

- 普通用户下载 `WarThunderResearchCalculator-v1.0.8-portable.zip`，解压后双击 `WarThunderResearchCalculator.exe`，无需安装 Node.js。
- `WarThunderResearchCalculator-v1.0.8.zip` 是开发者包，需要自行准备 Node.js 和安装依赖。
- 附带 SHA-256 校验文件。下载版不会自动获得未来网页更新；图片仍需网络加载。
