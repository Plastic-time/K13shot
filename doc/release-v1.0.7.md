# v1.0.7 界面与导航更新

## 本次更新

- 采用确认后的深色石墨界面，统一科技树卡片、折叠窗口、预算栏和截图的外观。
- 国家下拉框改为国旗选择面板；手机端为底部弹出面板，支持点击外部或关闭按钮退出。
- 军种改为图标标签，点击直接切换；手机窄屏可横向滑动。
- 删除顶部重复的国家、军种文字，保留载具数量和数据版本等信息。
- 国家、军种切换继续使用原有计划保存与加载流程。

## 桌面版同步

本次便携包还包含 v1.0.6 发布后已上线的改进：炮弹与机炮弹链采用更接近游戏的图标，手机配件窗口标题保持可见，科技树截图提高导出分辨率。超大科技树仍受浏览器画布尺寸与内存限制。

网页在线人数仍为浏览器估计数，桌面版不接入该统计。

## 保持不变

本次未更新载具与配件费用快照，未修改研发算法、等级门槛或前置关系。游戏数据基准仍为 2.59.0.17。精确规划仍为测试功能，实际研发前请在游戏中核对。

## 下载与使用

- 普通用户下载 `WarThunderResearchCalculator-v1.0.7-portable.zip`，解压后双击 `WarThunderResearchCalculator.exe`。这是 Windows 便携包，无需安装 Node.js。
- `WarThunderResearchCalculator-v1.0.7.zip` 为开发者包，需要 Node.js 24 LTS（24.21.0 或更高的 24.x 版本）。
- `WarThunderResearchCalculator-v1.0.7-SHA256SUMS.txt` 提供两个压缩包的校验值。
- 网页版：https://plastic-time.github.io/K13shot/

现有本地计划保存在浏览器中；请先解压到新目录，退出旧版本，再启动新版本。安装包不会自动更新。
