## 下载与使用

Windows 用户下载 `WarThunderResearchCalculator-v1.0.13-portable.zip`，解压到新文件夹后运行 `WarThunderResearchCalculator.exe`。若旧版仍在后台运行，请先退出旧版。无需另外安装 Node.js；不带 `portable` 的 ZIP 为源码包。

本次不改研发算法、费用、已选与已拥有状态规则、配件功能及其他界面。沿用 v1.0.12 的数据与已确认修正；保留居中头像名片及哔哩哔哩跳转。
