# 网页在线人数

## 使用与统计口径

网站地址仍为 <https://plastic-time.github.io/warthunder-research-calculator/>。标题附近显示“当前在线：N 人”，手机小屏幕自动换行，不覆盖科技树。数字表示近期活跃浏览器的估计数量，并非真实身份核验后的玩家人数，也不是累计访问量。

- 可见页面约每 30 秒上报一次，在同一次响应中取得人数；多个标签页共享匿名标识，支持 Web Locks 的浏览器会协调成一组上报。旧浏览器使用本地存储租约尽量减少重复请求，服务端仍按标识去重。
- 全部标签页进入后台、锁屏或关闭后停止主动上报。90 秒没有上报的标识不再计入，其他人看到的数字还需等下一次刷新，因此不会在关闭窗口的一瞬间减少。
- 一个浏览器多个标签页只计一次；不同设备、浏览器、浏览器配置和无痕窗口可能分别计数。关闭其中一个标签页不会把仍打开的另一个标签页踢出统计。
- 页面显示“暂不可用”时，可能是网络、浏览器隐私设置、后端故障或额度限制，不代表在线人数为零。载具选择、精确规划和配件计算独立运行。
- 桌面版不参与在线统计，现有安装包不需要更新。本地开发预览默认也不上报。

## 隐私与保存

请求仅发送随机生成的浏览器标识，不发送游戏 ID、邮箱、所选载具、研发计划或账户密钥。标识及最近结果保存在本站本地存储中，闲置 30 分钟后的下一次上报会换用新标识；关闭标签页不会物理删除本地存储。禁止本地存储时不启用统计。

后端保存有上限的匿名标识与最后活跃时间。每次计数先排除过期记录，下次成功写入时清理过期项；没有后续访问时，已过期的随机标识可能仍留在最后一份快照中。统计过期不等于承诺 90 秒后彻底删除数据。

IP 不保存在计数数据库里，但 Cloudflare 会处理连接信息，并用网络地址做临时限流。未开启应用请求日志，不记录上报正文；不承诺基础设施完全不接触 IP。浏览器里只有公开接口地址，没有 Cloudflare API 令牌。

## 查看用量

1. 在 Cloudflare 的 **Workers 和 Pages** 中打开 `k13shot-online`。
2. 查看 **指标 / Metrics** 中的请求、CPU 和错误情况。
3. 同时查看账户的 Workers 总用量，以及 **Durable Objects** 的请求、运行时长、存储读写；不能只看某个 Worker 的请求量。
4. 保持免费方案，不因故障提示而直接升级付费。账户下其他应用也可能占用额度。

免费额度和当前后端的 80,000 次每日写入保护说明见 [后端文档](../cloudflare/online/README.md#limits-and-failure-handling)。保护只限制本应用的正常写入，不能阻止恶意请求消耗账户请求额度，也不是付费账户的账单上限。

## 出问题时

1. 先刷新计算器页面，观察人数是否恢复。切回前台后可能需等待下一次上报。
2. 在 Worker 的 **设置 → 域和路由** 找到当前生产地址，浏览器访问它的 `/health`。正常会返回包含 `ok: true` 的 JSON；直接打开根路径返回 404 是预期行为。
3. `/health` 成功只证明 Worker 能访问，不能证明计数存储正常。浏览器开发者工具的网络列表中，`heartbeat` 请求成功应返回 `online`。
4. `403` 通常是来源不匹配；允许来源是 `https://plastic-time.github.io`，不包含 `/warthunder-research-calculator/` 路径。`429` 是频率限制；`503` 可能是服务异常、容量或每日预算限制。客户端会退避重试，不需不断手动刷新。
5. `workers.dev` 在部分访客网络上可能无法访问；先用手机流量与其他网络对比测试，不将这个问题误当作规划算法故障。

排查时分享状态码和经过遮挡的截图即可，不公开包含真实姓名、旧域名、账号信息或令牌的原始日志。

## 后续更新与暂停

- GitHub Pages 自动发布 `docs/`；统计后端使用独立的 `cloudflare/online` 目录，不要把部署路径改成仓库根目录。
- 在 Cloudflare 构建设置中，将构建监视路径限制为 `cloudflare/online/**`，并保持非生产分支构建关闭，减少无关提交触发构建。
- 修改账户的 `workers.dev` 子域名后，需要核验新的 `/health` 和真实心跳，再更新 `docs/index.html` 中统计脚本的 `data-endpoint`。新域名生效和 HTTPS 就绪可能并非即时完成。旧日志不会随改名自动清除。
- 需要暂停统计时，可将该 `data-endpoint` 清空后发布网页。此时不再发送统计请求，人数显示不可用，计算器仍可使用；已经打开的旧页面需刷新。
- 修改 Worker 代码后，等待 Cloudflare 构建成功并验证接口；不要删除 SQLite 类迁移记录或随意更改共享对象名称。

本地客户端测试：`node --test tools/test-online-client.cjs`。后端测试与部署检查见 [后端文档](../cloudflare/online/README.md#local-checks)。浏览器检查工具为 `tools/check-online-count.cjs`，需要测试环境安装 Playwright 和 Chrome；加 `WT_ONLINE_LIVE=1` 会对真实计数服务做短时访问测试并等待过期，不应高频运行。
