## 下载与使用

普通玩家下载 **WarThunderResearchCalculator-v1.0.5-portable.zip**，解压到新文件夹后双击 `WarThunderResearchCalculator.exe`，无需安装 Node.js。

开发者包为 **WarThunderResearchCalculator-v1.0.5.zip**；两个压缩包的校验值见 **SHA256SUMS.txt**。
