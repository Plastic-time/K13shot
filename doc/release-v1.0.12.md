# v1.0.12 界面与作者名片更新

- 桌面版同步最新界面：中文标题改为“战争雷霆研发计算器”，其他语言使用 Warthunder 品牌名；加入项目图标，游戏版本移至右上角。
- 作者名片在宽屏顶部居中，配有圆形头像。点击名片在浏览器新标签页打开“扑街的靓仔”的哔哩哔哩主页，不离开当前计算页面。
- 窄屏界面整理为紧凑标题与菜单，搜索、筛选和作者信息分别打开，保留原有选择状态。
- 网页版在线人数与载具数量并排对齐；桌面版不接入在线人数上报。
- README 更新中英文高清科技树与配件窗口截图、头像链接和下载入口。

## 下载与使用

Windows 用户下载 `WarThunderResearchCalculator-v1.0.12-portable.zip`，解压到新文件夹后运行 `WarThunderResearchCalculator.exe`，无需另装 Node.js。若旧版仍在运行，请先退出旧版；仅关闭浏览器标签页不一定会停止旧版后台服务。

点击作者名片需要联网。便携包不会自动获得之后的网页更新；不带 `portable` 的 ZIP 为源码包。

## 数据范围

本次只同步界面与打包内容，不改研发算法、载具及配件费用。整体载具数据基准仍为 **2.59.0.17**，保留已核对的 **2.59.0.34** CA-27 局部修正，以及 Ka-29、Do 217 J-2 的已确认修正。标题显示的游戏版本不代表全量数据升级。
