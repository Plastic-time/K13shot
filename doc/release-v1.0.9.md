# v1.0.9 规划交互与 Wiki 详情

## 自动规划后可继续调整

- 取消一个自动选中的载具，不再清空其他已规划载具。
- 等级补足载具可改为已拥有，保留其他选择并重新统计待研发预算。
- 再次选择被取消的自动载具时恢复原有角色，不会把整条路线改成目标。
- 路线草稿可随刷新保留；手动改动后不再显示此前的最优结果结论，重新点击“精确规划”才重新搜索。
- 折叠组内外的选择数量与状态同步，“清空计划”仍会清除已拥有标记。

## Wiki 小书签

- 载具卡片左上方增加小书签，点击打开 Wiki 详情窗口；配件入口仍位于卡片内，卡片尺寸不因此增大。
- 折叠载具同样支持；小书签缩小视觉尺寸并保留触控区域，增加手机间隙误触防护。
- 窗口支持重新加载、外部打开和关闭，关闭后卸载嵌入页面，不改变当前研发选择。
- 加载较慢时显示外部打开入口。Wiki 为第三方联网服务，可能出现验证提示、网络失败或嵌入限制；本次更新不承诺消除第三方错误。

## 保持不变

- 金鹰载具、礼包载具等分类标签、RP 0 / SL 0 显示及原有 BR 字号保持不变。
- 游戏数据基准仍为 2.59.0.17，保留 v1.0.8 的 Ka-29、Do 217 J-2 和两辆 CA-27 Mk.32 局部修正。
- 不更新载具或配件费用、等级门槛、前置数据和规划搜索算法。
- 网页和便携版同步上述交互；当前在线统计仍仅用于网页版。
