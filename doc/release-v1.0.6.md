## 下载与使用

普通玩家下载 **WarThunderResearchCalculator-v1.0.6-portable.zip**，解压到新文件夹后双击 `WarThunderResearchCalculator.exe`，无需安装 Node.js。

开发者包为 **WarThunderResearchCalculator-v1.0.6.zip**；两个压缩包的 SHA-256 校验值见 **WarThunderResearchCalculator-v1.0.6-SHA256SUMS.txt**。

## 本次更新

- 合并重复的规划入口：移除顶部和科技树右侧的规划按钮，保留底部研发总计右侧的“精确规划”，附“测试”标签。底栏采用半透明样式，滚动时保持可见。
- 手机长按载具约半秒，可打开“目标 / 已拥有 / 途经点”菜单；折叠窗口内也支持。轻点仍选择目标，滑动和多指操作会取消长按，松手不会自动选中菜单项。电脑右键保留。
- 使用指南补充电脑右键、手机长按及三种标记的含义，并更新底部规划入口说明。
- 配件 RP 和银狮均明确为 0 时，直接显示“已解锁”，自动计入配件等级数量，无需重复点击；清除操作不会撤销自动解锁，费用缺失不会视为 0。
- 桌面版恢复“金鹰载具 / 礼包载具”等分类标签，与配件“已解锁”状态分开显示。
- 安装包使用校验通过的 50 棵科技树、3,235 辆载具快照，配件覆盖 3,225 辆载具、52,430 个配件。
